What is saved?

User and assistant text, model names, dates, and source identifiers. ChatGPT export branches are retained and labeled. Images are marked when present; attachment binaries, internal reasoning, and tool logs are not included. Known API-token patterns are redacted; this is not a complete sensitive-data scanner.

For web chats, place the official export ZIP or conversations JSON into the inbox, then click Save missing chats. Other apps and Pet Program harnesses can supply the documented conversation JSON format.
